# 灯光控制

### 产品介绍


Light-Control 是一套专为教室、会议室及公共空间设计的智能灯光控制方案，是一个基于 ESP32-S3 的社团活动室灯光控制系统。它并非简单的开关控制器，而是一套以 **“稳定性与自愈能力”** 为核心的多路照明管理系统。系统支持本地按键与远程平台双重控制，并在网络波动或设备异常时能自动恢复，确保长期无人值守环境下的照明可靠性。


### 核心价值

*   **多路分区管控**：支持单路、联动、全开/全关等分组逻辑，适配复杂场景。
*   **双模控制**：现场按键即时响应 + 远程消息调度，体验一致。
*   **状态实时同步**：持续反馈设备真实状态，消除平台与现场的显示偏差。
*   **故障自愈**：断线自动重连、备用通道切换、异常重试及安全模式兜底。
*   **OTA 与诊断**：支持在线安全升级，内置完整事件日志，便于远程运维排查。


### 技术工作栈

该系统采用 **Python** 作为核心开发语言

| 层级 | 技术 / 组件 | 说明 |
| :--- | :--- | :--- |
| **核心语言** | Python (100%) | 系统逻辑、控制策略、状态管理及通信协议均使用 Python 实现 |
| **通信协议** | MQTT  | 通过 Python 生态库实现与云端平台及底层硬件的通信 |
| **并发模型** | asyncio / Threading | 处理多路灯光控制、状态监听与网络重连等并发任务 |
| **持久化** | SQLite / JSON | 本地状态存储、日志记录及 OTA 版本信息管理 |
